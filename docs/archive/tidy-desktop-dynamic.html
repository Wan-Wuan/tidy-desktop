从混乱到稳定，只走三步

真正的动态网站应该让人知道下一步做什么。这套流程对应 Tidy Desktop 的实际上手路径。

扫描导入

扫描桌面和开始菜单，自动收集快捷方式、文件夹和常用入口。

自动归类

按来源或规则创建分类，把分散入口放进更容易理解的区域。

快捷启动

通过主窗口浏览分类，通过搜索窗口输入关键词快速打开目标。

下载最新安装包

页面会自动查找最新 GitHub Release。若网络无法访问 GitHub，可进入发布页手动选择安装包。
