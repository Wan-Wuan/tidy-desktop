几个可能需要你定夺的点：
  • 圆角：A/B 用 8px 直角感，C/D 更贴合输入行。想要更圆可以改回 999px 胶囊。
  • 字号：A/B 是 13px，C 是 14px，D 与输入一致 15px。字号越大越"融入"。
  • × 按钮：A/B 默认可见（浅色），D 默认半透明、悬停才明显。要不要一直显示？
  • 长名称：A/B/C/D 都已预留 ellipsis，名称过长会截断显示，不会撑破布局。
  • 颜色：目前跟随主题主色（indigo）。如果你改了主题色，徽章会一起变。
