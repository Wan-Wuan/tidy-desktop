方案 A 淡色融合
10% 主色淡底 + 深靛蓝文字，圆角 8px，13px 字号。轻微底色让它可辨识，又不抢戏。
Bing
方案 B 细描边
透明底 + 32% 主色描边，13px。比 A 更轻，边界清晰。
Bing
方案 C 纯文字 + 分隔竖线
无背景，仅靠颜色和右侧 1px 竖线与输入区隔开，14px。像"输入框前缀标签"。
Bing
方案 D 完全融入输入行
无背景无描边，15px 与输入文字完全一致。最隐形，视觉负担最小。
Bing
方案 E 胶囊（圆角 999px）
12% 主色淡底 + 全圆角胶囊，13px。保留一点"徽章感"，但已无图标无 ×，比原来的实心渐变轻盈很多。
Bing

去掉 × 之后的注意事项：
  • 清除引擎只剩 Backspace（输入框为空时按）和 Esc 两条路径，这两个都已正常工作。
  • 徽章现在是纯展示元素，不可点击——视觉上也更符合"它就是个状态标签"的直觉。
  • 圆角：A/B 是 8px，C/D 更贴合输入行，E 是 999px 全圆胶囊。
  • 字号：A/B/E 13px，C 14px，D 15px（与输入一致）。
  • 颜色：跟随主题主色，改主题色徽章会一起变。
